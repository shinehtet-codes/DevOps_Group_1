# DevOps Group 1

Population reporting system developed using Java, Maven, Git, GitHub, Docker and GitHub Actions. The project uses Scrum and DevOps practices to deliver population reports from an SQL database.

## Project Overview

This project is being developed as part of the **SET09803 DevOps** module.

The system will provide population reports covering:

* Countries
* Cities
* Capital cities
* Population statistics
* Language populations

## Technologies

* Java
* Maven
* IntelliJ IDEA
* Git
* GitHub
* Docker
* GitHub Actions
* SQL

## Development Methodology

The project is developed using **Scrum**, with the team working through Sprints, User Stories, GitHub Issues, and Project Boards.
